# Auditorías SEO

Aquí se guardan los informes de la skill `/seo-audit`, uno por auditoría, con el nombre
`auditoria-AAAA-MM-DD.md`. Sirven como historial: qué se encontró, qué se corrigió y qué quedó
pendiente.

Cómo auditar: [guía de SEO](../guias/seo.md). El formato del informe está en
[la plantilla de la skill](../../skills/seo-audit/references/report-template.md).
